# 冰河地形工作室 V4 — 單一 3D 工作視窗

## 這次更新

- **同一個 3D 工作視窗**：地形積木選擇、手繪工具、立體預覽都在同一區。2D 等高線縮成右上角可開關的小視窗。
- **教科書式立體地景塊**：地形上表面依海拔與坡面陰影設色，四邊有分層土色側壁與底面。側壁岩土層屬視覺示意，不代表真正地層年代或厚度。
- **融冰水示意水道**：藍色河道可開關，會貼近地表但不改變高程，也不是根據水文演算得出的河道。
- **3D 直接編輯**：選地形積木後點地表放置；「選取／移動」點模型上的圓點並拖曳移動；選擇手繪工具後直接在 3D 地形上塗繪抬升、下切、平滑、整平。切換「旋轉觀察」才能自由拖曳旋轉視角。
- 保留 20×12 到 180×108 km 範圍、初始四角高程、真實高程資料匯入、學生 A4 PNG、ASC、GLB 與 JSON 專案。

## 安裝／更新

1. 在 GitHub Pages 對應的儲存庫，備份舊版檔案。
2. 將 **index.html、style.css、app.js、terrain-core.js** 全部上傳至根目錄，覆蓋同名檔案。
3. 等 GitHub Pages 發布後重新整理（可以在網址加上 `?v=4`）。
4. 需有網路載入 Three.js CDN。若載入失敗，可先用右上角的「2D 等高線」檢查內容。

## 開始操作

1. 點「載入虛構冰河教學地景」。
2. 看中央大型 3D 工作區，左上角浮動工具框選「冰斗」，然後**直接點 3D 地表**放置。
3. 點「選取／移動」，拖曳模型上的小圓點調整位置；在空白處拖曳可旋轉。
4. 點「下切谷地」，在 3D 地表持續拖曳雕塑谷地；切回「旋轉觀察」可旋轉。
5. 需要看等高線時，點工作區上方「2D 等高線」。
6. 開啟或關閉「顯示融冰水示意水道」、「3D 上顯示等高線」。
7. 下載 **GLB** 模型或 **A4 學生等高線 PNG**。

## 重要限制

- 「角峰」「冰斗」「鼓丘」等是可調整的**形態模擬積木**，不是地貌形成過程的物理模型，也不能用等高線單獨確認成因。
- 雪白色表示本模型相對高海拔的示意分層設色，**不是實測雪線**。
- 水道是視覺輔助示意，可能不完全符合地勢最低線與真實流向。水道可連同 GLB 一起匯出，但不改變 DEM／等高線。
- 底座岩土顏色層屬造型，並不是實際地質剖面。
- 80×48 km 模型的 300×180 高程格網每格約 268 m；要教細小蛇丘或羊背石，應以 20×12 km 尺度編輯。
- 這是網頁版的實際程式，但此環境無法完全載入外部 Three.js 進行 WebGL 實機驗證，故請在 GitHub Pages 的瀏覽器上測試 3D、拖曳、GLB 功能。

# 冰河地形工作室 V4.3 — 兩頁積木與堆積／侵蝕

V4.3 延續 V4.2，將地形積木分成兩頁，保留原有真實 DEM 載入、邊界高度、手繪塑形、2D 等高線、實心模型及 GLB/ASC 輸出。

## 新功能

### 第 1 頁：純幾何圖形

- 三角錐：三角形底面的尖峰模型。
- 圓錐：圓形底面的尖峰模型。
- 球體（半球地表）：以球體露出地表的半球形輪廓建立圓頂山或圓形凹坑。
- 長方體：平頂、四側陡峭的高台或凹穴。
- 圓柱：圓形平頂台地或凹穴。

每次放置前都可以選「＋ 堆積／抬升」或「－ 侵蝕／下切」。選擇後會預覽圖形，滑到 3D 模型上會出現半透明位置提示；點擊後將形狀轉換為高程網格。放置後可在右側編輯面板修改該個積木的堆積／侵蝕、強度、尺度、角度及平滑程度。

### 第 2 頁：冰河地形

保留角峰、刃嶺、冰斗、冰槽（U 型谷）、羊背石、鼓丘、蛇丘、端磧、冰水沖積平原與沙丘。這些是地形形態示意，不代表能僅由外形證明成因。

## 如何安裝／升級

1. 解壓縮 ZIP。
2. 將 `index.html`、`style.css`、`app.js`、`terrain-core.js` 四個檔案全部上傳 GitHub Pages 儲存庫根目錄，覆蓋舊版本。
3. GitHub Pages 更新後，重新整理，必要時以網址 `?v=4.3` 強制瀏覽器抓取更新後的首頁。
4. **保留舊專案的 JSON 備份**。V4.3 支援讀取 V4.2/V4.1/V4/V3/V2 的專案 JSON；新的儲存格式為 `glacier-studio-v4.3`。

## 建議測試順序

1. 「建立 600 m 平坦地表」。
2. 點「第 1 頁｜幾何圖形」，選「堆積」，再選三角錐，在 3D 地表點擊放置。
3. 點「2D 等高線」，確認閉合等高線與山體相符。
4. 改為「侵蝕」，選球體，另選位置放置，確認產生凹坑。
5. 選取剛放的球體積木，在右側的「幾何積木的作用方式」由侵蝕改堆積，確認結果反向。
6. 點「第 2 頁｜冰河地形」，放入冰斗或冰槽，確認既有積木仍可操作。
7. 儲存 JSON，重新載入並確認每個幾何積木原有的 `operation` 屬性不變。匯出 ASC/GLB/A4 PNG 檢查結果。

## 技術限制

本系統以高程網格表示一塊地表（每個水平位置只有一個高度），因此球體表示球面露出地表的一部分，無法保留封閉洞穴、倒懸或地下球體。幾何體是用於控制地表起伏的**造形原型**，放置後會融入地面，而不是永久浮在地表上的獨立物件。邊緣柔化與網格解析度會影響形狀的銳利程度。

測試環境已完成 2D UI、兩頁切換、操作方向、存檔與高程運算測試。3D Three.js 預覽以及 GLB 匯出仍需在實際 GitHub Pages 瀏覽器與 iPad 上驗證。

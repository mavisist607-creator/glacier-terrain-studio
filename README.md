# 冰河地形工作室 V3｜實心地形 × 國家公園尺度 × 手繪

本版本專注在地形及等高線，沒有 AR 功能。

## 快速開始

1. 解壓縮，把 `index.html`、`style.css`、`app.js`、`terrain-core.js` 上傳至 GitHub Pages 儲存庫根目錄。四個網站程式檔必須放在同一層。
2. Safari 或 Chrome 開啟頁面。3D 預覽與 GLB 匯出使用線上的 Three.js CDN，需要網路。
3. 左側「建立地形與邊界高度」選 20×12、50×30、80×48、120×72 或 180×108 公里。
4. 四角高程是西北、東北、西南、東南的起始高程，系統會在地表中作雙線性過渡。若需要全片同海拔，輸入統一高度，按「套用四角」。
5. 按「依邊界高度建立新地表」。若原本載有積木，會詢問是否清除。
6. 在左側地形積木區選擇角峰、冰斗、冰槽、端磧等，點擊 2D 地圖放置，或在右側調整選取積木的高度、長寬、方向。
7. 在「手繪地形」選擇抬升、刻蝕、平滑或整平。在左側 2D 地圖按住拖曳；設定「筆刷半徑（公里）」、「每筆強度（公尺）」和整平目標高程。
8. 在右側「地形與等高線設定」調整實心底座厚度、垂直誇大、等高距；最後匯出 GLB、A4 PNG 或 QGIS ASC。

## 重要功能

- **實心 3D 視覺地形**：模型由頂面、四周側壁與底面組成。GLB 也匯出相同封閉外觀；尚未做 3D 列印的流形／水密驗證。
- **國家公園尺度**：預設 80×48 km，最大可選 180×108 km。只是畫布涵蓋尺寸，不會自動對應實際國家公園行政邊界。
- **四角邊界高度**：四角可分別指定高程，也可設定全區一致高程。勾選「保持最外圈高程」時，積木不能改變最外圈格網高度。
- **手繪塑形**：手繪直接修改原始高程底圖，地形積木疊在其上。按「撤銷」復原一筆畫；繪製中的高程也會重新生成等高線。
- **舊版資料**：可匯入 V2 JSON，將 180×108 格網重取樣為 V3 的 300×180 格網。建議另存為 V3 JSON。
- **真實 DEM**：沿用原本 ASC、GeoTIFF、Terrarium PNG 匯入；單一線上圖磚不會自動覆蓋整座國家公園。需要完整範圍請從 QGIS 裁切／合併後匯入 DEM。

## 精度限制（教學時非常重要）

V3 網格為 **300×180**。若場景寬 80 km，水平網格約 268 公尺／格；若寬 120 km，約 401 公尺／格。這種範圍適合呈現整體冰河谷及山區，但無法保證保留數十公尺尺度的蛇丘或小型鼓丘。

若要讓學生判讀小型地形，請改用 **20×12 公里** 或較小的局部 DEM。國家公園全景與微地形判讀應做成兩個不同尺度的模型，不要誤以為放大視角就能補回原本不存在的細節。

## 已驗證與尚需現場測試

已透過瀏覽器確認：四角高程建立、場景尺寸、筆刷修改 ASC、高程撤銷、積木新增、舊專案匯入、A4 PNG 與 ASC 下載。另以程式檢查確認封閉地形幾何包含側壁和底面。

因測試環境未能載入 Three.js CDN，**3D WebGL 預覽與 GLB 下載仍須在你的電腦或 iPad 實測**，並檢查 GLB 在 Blender 等檢視器的外觀。
